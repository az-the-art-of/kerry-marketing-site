A responsive static website concept for Kerry Marketing, designed for GitHub Pages.

- `` — Contact
- `contact.html` — Contact

## Preview locally
Open `index.html` in a browser. No build process is needed.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `kerry-marketing-site`).
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will provide the published URL after deployment.

## Before launch
- The contact form is currently a front-end preview only. Connect it to Formspree, Netlify Forms, or an email/backend workflow to receive submissions.
- Add verified contact details, current vacancies, company details, and any approved charity partner logos or testimonials.
- Review all wording for factual accuracy and update to match the company's current services.
- The site imports Manrope and DM Mono from Google Fonts; a network connection is required for those fonts. System fallback fonts are defined.
- If connecting a custom domain, configure it in GitHub Pages and update DNS records with your domain provider.


The site is responsive across desktop, tablet, and mobile screens, with a mobile navigation toggle and reduced-motion support. The Careers page and Careers navigation/promotional section have been removed per request.


Latest visual update: background surfaces use a soft light-grey palette; the homepage includes a team photo feature with responsive framing and additional subtle motion. Existing animations remain and reduced-motion settings are respected.
